# Repetition and vocabulary diagnostics

These are qualitative editorial prompts, not a word-frequency dataset, validated detector or disciplinary benchmark. No universal frequency ceilings are prescribed. Technical terms and formal statements take priority over stylistic preferences.

| Pattern to inspect | Question | Possible edit |
|---|---|---|
| admissible, legal, allowed | Is the technical distinction needed here? | Define the class once and refer to it plainly. |
| explicit, precise, exact | Does the modifier change a checkable claim? | Give the constant or relation, or remove the empty emphasis. |
| baseline, budget, envelope | Has the underlying quantity been defined? | Name or gloss the quantity at first use. |
| rather than, does not imply | Does this contrast prevent a real misreading? | Keep a substantive contrast; remove repeated self-protection. |
| stated range, specified conditions | Can the reader locate the actual condition? | Name the condition or point to its definition. |
| retained, saturation, onset | Is this ordinary prose or a necessary term of art? | Use a plain description where it preserves the meaning. |

## Structural patterns

- Several adjacent sentences list claims without explaining their relation.
- A paragraph ends with the same qualification already attached to its result.
- A symmetric upper/lower pair repeats itself without making a comparison.
- Several consecutive sentences begin with the same generic phrase.
- A section closes with a summary that names no finding or consequence.

Inspect the passage in context. Change it only when the edit improves the reasoning or prevents a misreading. Never substitute a synonym merely to reduce a count, delete a truth-changing condition or weaken a technical term.
