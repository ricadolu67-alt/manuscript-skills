# 最强成立版本｜先找成立范围，再决定改窄或撤回

两个程序。A 在主张失败、存疑或被评审指为“过强”时使用；B 在每次 `BUILD` 对全部 `DECISIVE` 主张至少做一次，`UPDATE` 时对受影响主张再做。两者结果都写入内部层 I5，成立的推论写入对外层 P4。

## A｜改窄先于撤回

1. **定位失败点。** 是哪一个量词、参数、比较对象、极限或方向不成立？写成“原主张在 X 处失败”，而不是“原主张不成立”。
2. **列候选限制**（只列与失败点相关的）：
   - 参数区间（步长、维数、时间、雷诺数、浓度……）；
   - 问题类（域、正则项、材料、数据分布）；
   - 比较对象（固定比较点 vs 全域最优；精确基线 vs 理论上界）；
   - 方向（充分 vs 必要；上界 vs 下界）；
   - 精度层级（常数级 vs 阶级；渐近 vs 有限时间；最坏情形 vs 典型）；
   - 证据范围（所测参数范围；已证特例 vs 一般情形）。
3. **先查已有结果能否直接推出受限版本**。很多“需要新证明”的结论其实只是两条已证结果的组合，例如“充分条件 + 下界构造 ⇒ 在基线被主导的区间内为紧”。
4. **选最强的真版本**，写成新的 `statement`，把限制写进 `truth_conditions`，把失败的原版写进 `do_not_say`。取**最宽**的成立区间：能写“η²T ≳ D 时成立”，就不要只写“η²T ≍ D”或某个平衡点；能写有限时间，就不要退到渐近。
5. **记结局**：`KEEP`（原版本成立，质疑不成立）/ `RESCOPED`（受限后仍是同类结论）/ `WEAKENED`（只剩较弱一类结论，例如只剩充分性）/ `WITHDRAWN`。
   - 只有在找不到非平凡受限版本，或救回它需要新的研究工作时才 `WITHDRAWN`；后者同时记为开放问题或后续任务。
6. **止损**：最多两种思路；记录卡在哪里。

## B｜防写弱扫描

对每条 `DECISIVE` 主张问：

- 上下界是否已在某区间匹配，却分开陈述？→ 写成 Θ（注明区间）。
- 与最接近先例相比，是否已有改进、分离或统一，却没点明？要对照先例的**每一族结果**（例如光滑情形、熵情形、障碍情形），不只对照最接近的那一条；跨族的分离常常是最有信息量的推论。
- 证明已覆盖一般情形，却只陈述了特例？
- 是否有一两步就能推出、且值得读者知道的推论？
- 数值或实验已覆盖的范围，是否比陈述的更宽？
- 有没有有信息量的负结果被当作“局限”藏起来？
- 哪些项**不随可调参数变化**（步长、正则强度、样本分配）？调不掉的代价往往是最该告诉读者的事，也常常就是与先例的分离所在。
- 已证明的结论只因缺经典引文或缺独立复核而没进对外层？这两类缺口进 I6 或引文请求，主张照常列出（`assertion` 按不变式 6 判定）。

发现的每一项：可直接成立 → 写入 P4，并注明 `from`、`regime`；需要额外工作 → 写入 I6，注明工作量。

## 理论论文的常用正确说法

| 想说的 | 正确的有界写法 |
|---|---|
| 某条件是必要的 | “在参数区间 R 内（R 使精确计算的保证为 g），若 ε ≥ C·f 则存在实例使遗憾 ≥ c√C·g；而 ε ≤ c·f 足以保持 g。故在 R 内阈值为 Θ(f)。” |
| 上下界匹配 | 写清匹配的是哪一项（总遗憾，还是精度带来的那一项）、在什么区间、差几倍常数、何时饱和。 |
| 渐近结论 | 写清对每个固定实例成立还是一致成立；不一致时说明不一致在哪里。 |
| 依赖未证不等式 | `assertion = CONDITIONAL`，把不等式写进 `truth_conditions`；不要用“我们相信”来掩盖。 |
| 只验证了数值 | `assertion = NUMERICAL`，写清覆盖的参数范围。 |

## 反模式

- 因一个量词失败而撤回整条结论。
- 用含混措辞（“comparable”“in some sense”）代替一个精确的受限版本。
- 把内部核验缺口（未独立复核、未重跑）转成正文里的限定语。核验缺口属于 `gate_status`。
- 撤回后不留痕，导致下一轮又被写回原来的过强版本。

## 教学样例

考虑实数上的二次函数 f(x)=x²。错误主张“f 在整个实数轴上严格递增”可由 x=-2 与 x=-1 直接否定，但不必撤回所有单调性结论。

限制到 x≥0 后，若 0≤x<y，则 y²-x²=(y-x)(y+x)>0，因此严格递增成立。结局为 `RESCOPED`，`truth_conditions` 写非负定义域，`do_not_say` 写“在整个实数轴上严格递增”。

这是格式与逻辑的教学样例，不代表新研究发现。完整示例见 [quadratic_demo_LEDGER_PUBLIC.md](../examples/quadratic_demo_LEDGER_PUBLIC.md)。
