# Review Status Rules｜审查状态与阻断传播

先声明任务模式、材料版本、保留的主张、所需检查和依赖图，再汇总状态。这里是规则与模板示例，不是对任何实际稿件的正式验收。

## 紧凑决策表

按表中顺序判断；单项状态和关键性定义见 [check_record_schema.md](check_record_schema.md)。

| 条件 | `gate_status` | 稿件审查结果 | 必须报告 |
|---|---|---|---|
| 未开展实质审查，例如只做了新颖性初筛 | NOT_ASSESSED | NOT_ASSESSED | 已完成的工作；科学审查未完成及已知疑点 |
| 已实质审查，任一 `required_for_main_claim=TRUE` 的检查为 FAIL、NOT_CHECKED、UNAVAILABLE 或 INCONCLUSIVE；关键依赖节点受阻；或有其他已知阻断 | HOLD | HOLD | 受影响主张、记录、依赖路径和最小解除条件 |
| 已实质审查，可能影响主贡献的关键性/适用性仍 UNKNOWN，无法确认所需关键检查已覆盖 | HOLD | HOLD | 尚缺的判断依据，不能默认降为非关键 |
| 所有关键要求已通过或有依据地不适用，无已知阻断，仅剩具体、可解决的非关键审查补项 | CONDITIONAL | CONDITIONAL | 补项、非关键理由、解决方法；完成后重新汇总 |
| 已实质审查，所有适用关键检查真 PASS，不适用项有依据；无已知阻断及待办审查补项 | PASS | SCIENCE_REVIEW_PASS (scope-limited) | 范围、版本、证据与记录、非关键排除项及理由、未取得的独立确认 |

未取得作者批准、责任确认或投稿授权，作为独立确认状态报告，不伪造记录、不由审查结果推导；这不自动改写科学轨检查结论，也不允许执行未授权的投稿或其他外部操作。正式必需的伦理/数据等问题若本身构成已知阻断，应在相应审查轨给 HOLD，不能伪装成普通待签名事项。

**范围限定不能绕过关键缺口**：仍保留的主贡献所需检查，不能因本次只读过部分材料而排除。已实质审查且发现核心未决，则相应审查 HOLD。PASS 只表示声明范围内的检查结论，不是独立科学认证、人工批准或接收预测。

## 依赖阻断与主张修订

按 [claim_dependency_map.md](claim_dependency_map.md) 的类型和目标方面逐条判断。仅真正必要的REQUIRES传播先决阻断；SUPPORTS失效不自动否定目标，CROSS_CHECKS各自审查且不相互传递通过，CONTRADICTS触发范围核对与冲突调查。EXPLAINS受阻首先限制解释，不自动否定独立观测；机制归因若必须依赖该理论，须为归因主张另列REQUIRES。未知关系若可能影响主贡献，先HOLD，不能默认是非必要支持。

下游PASS不能解除其必要前提缺口；独立观测也不能使失败的理论证明通过。若观测量由该理论校准/反演，导出结果同样可能受阻，不能仅凭实验标签保护它。对独立性按需使用 [independence_profile.md](independence_profile.md)；实现不同但共享错误边界条件，不能提供该边界条件的独立物理验证。

保留的主贡献包含受阻分支或影响它的重要冲突，整体HOLD；同时分别报告仍可成立的独立结果及其自身检查状态，不把“受阻”写成“已证伪”。只有明确修订保留主张并重新审查后才可改变整体状态。

改窄或移除主张前，先按 [strongest_claim.md](strongest_claim.md) 寻找成立范围；结局记入内部层 I5。允许明确收窄或移除主张。先保留原问题记录，再记录新主张/版本、更新依赖图与检查清单、解释旧阻断是否仍相关，重新做必要审查和新颖性初筛。不能自动删除失败项、改为 NOT_APPLICABLE 或把旧 PASS 继承为新版本全通过。

## 八个可核对示例（假设情境，不是执行/批准记录）

| # | 可核对输入条件 | 应输出及理由 |
|---|---|---|
| 1 | 只做了新颖性初筛；没有执行科学核验 | 初筛结论照实报告；科学审查 NOT_ASSESSED，不能称已通过。 |
| 2 | 主要结论依赖网格无关性；标签 MAJOR，`required_for_main_claim=TRUE`，状态 NOT_CHECKED | HOLD；MAJOR 并不等于非关键，可补做也不能先 CONDITIONAL。 |
| 3 | 守恒是模型有效性的必要条件；该检查 CRITICAL/TRUE/FAIL，但图形和步长检查 PASS | HOLD；其他检查 PASS 不覆盖该失败。 |
| 4 | 主贡献独特性依赖最接近先例的关键内容；材料 UNAVAILABLE，所需比较为 TRUE | HOLD；记录访问障碍，不能说不存在先例或用访问失败作通过依据。 |
| 5 | C1 闭合假设的判别检查 TRUE/INCONCLUSIVE；C2、C3 必须依赖 C1，C2 数值复现 PASS | C1 及受影响下游 HOLD；复现未解除先决条件未决。 |
| 6 | 一个主张登记三项必需检查，其中一项 PASS，另两项 NOT_CHECKED；或后两项是否关键仍 UNKNOWN | HOLD；一行 PASS 不能代表全主张；须补全要求和当前有效记录。 |
| 7 | 所有关键科学检查 PASS；只剩不影响结论的局部图例补项 MINOR/FALSE，可直接修正 | CONDITIONAL；列明补项，修正核对后重新汇总，不能把主贡献所需图例信息误标为 MINOR。 |
| 8 | 当前声明范围内所有适用关键检查 PASS；例如纯理论稿的仪器校准有依据 NOT_APPLICABLE；无其他阻断或补项；未取得作者批准 | SCIENCE_REVIEW_PASS (scope-limited)；同时单列作者批准/投稿授权未取得，不能生成确认或自行投稿。 |

这些示例验证状态规则的逻辑覆盖，不构成真实稿件测试、A/B 结果、科学验收或任何人的批准。
