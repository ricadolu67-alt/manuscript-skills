# Discussion

- **Open with what the results change together**, in one paragraph. Do not restate every theorem.
- **Open problems come from P6 only.** Write each as a research question: why it is hard, and what route might work. Internal to-dos, unrun checks and packaging issues do not belong here.
- **Put each limitation where it changes how a result can be used.** No generic Limitations list.
- **Relation to prior work:** if the introduction already covered it, add only new implications here.
- **Required statements** (data, code, AI use, conflicts) go where the venue asks for them. Write them as true facts; never invent or confirm them on the authors' behalf.
