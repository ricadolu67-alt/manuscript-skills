# Defensive versus direct: teaching examples

These invented examples demonstrate editing decisions. Their numbers and scenarios are teaching material, not experimental results, quotations, benchmarks or claims about an existing manuscript. They must not be copied into a research paper as evidence.

## Three questions for a qualifying sentence

1. Which claim does it protect, and from which misreading?
2. Has the formal statement or model section already supplied the condition?
3. If it must remain, can it be stated once, positively, at the point of use?

Keep every truth-changing condition in its formal statement and every `reader_condition` where the claim is made. Remove a repeated qualifier only when the resulting passage remains true and unambiguous. If a prior-work comparison is unsupported, narrow it or return it to the scientific role; do not turn uncertainty into an unsupported confident claim.

## Worked pairs

| Pattern | Before | After | Decision |
|---|---|---|---|
| Exclusion list | We consider a model with time dependence and spatial variation excluded. | We study a steady, spatially uniform model. | Name the setting. |
| Finding hidden behind procedure | In the calculations performed here, doubling the batch size was observed to reduce the iteration count from 80 to 45. | In the tested cases, doubling the batch size reduced the iteration count from 80 to 45. | Keep the numerical scope and state the observation. |
| Abstract label | A separation between the two responses is resolved. | The two responses have opposite signs at the same forcing. | Name the event, if supported. |
| Empty summary | These results highlight the importance of the threshold. | Above the threshold, the fixed point becomes unstable. | Give the consequence. |
| Unfocused comparison | Our problem differs from previous settings in several respects. | We ask how the threshold changes when the forcing varies in time. | State the question; support specific comparisons separately. |
| Repeated scope | For symmetric matrices, the rate is quadratic. This is only for symmetric matrices. | For symmetric matrices, the rate is quadratic. | Remove the immediate duplicate. |
| Generic limitations | The model has limitations that should be considered. | The model assumes constant diffusivity; concentration-dependent diffusivity requires a new closure. | Name the limitation that changes use. |
| Unclear borrowing | The earlier measurement motivates our trend without identifying parameters. | We use the measured direction of the trend; the parameter values are fitted separately. | State what is borrowed. |
| Double negative | A single exponent does not rule out alternative mechanisms. | Distinguishing the mechanisms requires both the exponent and the transient response. | State the discriminating test, if established. |
| Hidden positive result | Although the tested response increases over the parameter interval, the smallest parameter need not give the largest signal. | Over the tested interval, the signal increases with the parameter. | Give the supported range and direction. |
| Detached requirement | Prediction requires additional calibration. | Predicting the transient response requires a measured relaxation time. | Connect the requirement to its purpose. |
| Unsupported priority | To our knowledge this is the first general result. | The result extends the stated bound from a fixed dimension to all positive dimensions. | Use a verified comparison; otherwise request verification. |
| Vague title | Interpretation and scope | When the constant-diffusivity approximation holds | Name the question. |
| Excess digits | The measured response is 0.237194826. | The measured response is 0.237. | Round only if the measurement supports three significant figures; preserve uncertainty. |

## Applying the examples

Use the patterns to diagnose writing choices, not to impose a replacement sentence. A condition required for truth stays even when it makes the sentence longer. A numerical observation stays numerical. A negative finding remains a negative finding when that is the scientific result.
