# 使用指南

## 选择入口

| 需求 | 入口 |
|---|---|
| 尚未形成科学账本，准备从研究材料写论文 | `science-ledger` BUILD |
| 新结果、条件或审稿证据改变了已有主张 | `science-ledger` UPDATE，仅更新受影响部分 |
| 评估当前材料的科学审查就绪度 | `science-ledger` READINESS |
| 已有有效对外账本，起草论文或一节 | `paper-author` DRAFT / SECTION |
| 按现有账本调整现稿结构 | `paper-author` RESTRUCTURE |
| 编辑有账本的现稿或核对保真 | `paper-editor` EDIT / CHECK / FULL |

无账本的普通段落润色、投稿附信或审稿回复，可使用工具的一般写作能力或另外安装的专用技能；它们不是本项目依赖。

## 最小提示词

以下 `$skill-name` 写法可用于支持该语法的工具。其他工具可从技能选择器选择，或使用技能名称明确调用。请把材料位置、目标与写入范围替换成实际值。

### 整理研究材料

```text
使用 $science-ledger 的 BUILD 模式。
根据提供的研究笔记、推导和结果，整理贡献、成立条件和证据范围。
输出 LEDGER_PUBLIC.md、LEDGER_INTERNAL.md 和 checks.csv 到指定新目录。
保留原材料；未授权的新计算只列为建议，不执行。
```

账本字段、证据状态和模板见 `skills/science-ledger/`。`truth_conditions` 保留完整成立条件；`reader_condition` 概括读者容易误解的条件。可精简、合并或拆分主张，不能为满足数量目标删除决定真假的条件。

### 从账本写稿

```text
使用 $paper-author 的 SECTION 模式，为目标期刊撰写 Introduction。
科学断言仅以提供的 LEDGER_PUBLIC.md 为依据。
可读取当前待改稿和与账本一致的图件，不读取内部账本或检查记录。
保留现稿，另存新稿，并交付 TALK_NOTE.md、AUTHOR_NOTES.md、EDITOR_HANDOFF.md。
若缺少科学支持，提出账本更新请求，不补造结果。
```

首次写全稿用 DRAFT；调整现稿结构用 RESTRUCTURE。格式按需求选择，LaTeX 不是唯一输出形式。范文为可选输入，缺失时依照包内写作标准继续，不阻断任务。

### 编辑并核对

```text
使用 $paper-editor 的 FULL 模式。
输入为当前稿件、同版 LEDGER_PUBLIC.md、单独的 I7 评审摘录及 EDITOR_HANDOFF.md。
保留原稿，输出编辑稿、EDIT_NOTES.md 和 CHECK_REPORT.md。
不读取完整内部账本、原始核验记录或完整 AUTHOR_NOTES.md。
将内容判定与编译环境问题分别报告。
```

编辑交接只记录账本版本、开场选择及理由、口头说明顺序、Tier C 偏离理由，不包含新增科学断言或内部核验信息。旧稿缺交接文件仍可处理，但不能假称读过缺失材料。

## 上下文与材料

各角色宜使用新的、相互隔离的上下文，以便遵守各自的材料边界。可以手动开启会话；没有自动编排器也能使用。不要求特定模型、执行池、调度器或额外账号。

| 角色 | 可读材料 | 不应传入 |
|---|---|---|
| 科学整理 | 本次授权范围内的原材料、推导、数据和评审证据 | 无关私密材料和凭据 |
| 写作 | 对外账本、目标稿型、按需的现稿及一致图件 | 内部账本、checks、原始推导、评审答案 |
| 编辑 | 当前稿、同版对外账本、I7 单独摘录、编辑交接 | 完整内部账本、完整作者笔记、原始检查日志 |

用户自己的访问权限、保密要求及项目规则始终适用。技能不授予上传、发送、发布、署名或批准权限。

## 判定与返工

`RETURN_TO_LEDGER` 表示需要调整科学账本；`RETURN_TO_AUTHOR` 表示需要重建叙事；`FIX` 表示可在已有科学与叙事范围内修改；`PASS` 表示所检查内容满足当前规则。`PASS` 不自动解锁投稿或替代独立验收。

核对返回后按问题类型处理，最多两轮；仍有问题则明确交付剩余项。编译、字体和工具链问题单独报告为 Environment，不替代内容判定。

## 常见问题

**必须安装其他论文技能吗？** 不需要。三个模块及其指引、模板已包含在项目内。检索、绘图、编译等能力由宿主工具另行提供。

**没有范文全文能运行吗？** 能。可以提供合法持有的范文；没有时使用内置标准，记录范文不可得，不编造阅读经历。

**是不是论文自动认证工具？** 不是。账本和核对报告只能如实记录实际材料及检查；科学判断与正式批准仍需按项目要求完成。

**能直接覆盖现有论文吗？** 建议保留原稿并另存版本。写入范围与是否覆盖应由具体任务授权决定。
